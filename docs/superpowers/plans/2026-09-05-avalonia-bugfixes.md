# Исправление ошибок Avalonia

Цель: воспроизвести ошибки текущей версии и исправить их без новых зависимостей в приложении.
Основание: запрос пользователя от 5 сентября 2026 года.
Подход: отдельная тестовая копия приложения, регрессионный тест перед каждой правкой, проверка общего diff и полного набора тестов.

- [x] Копирование и очистка: сохранить метку архива, ограничить очистку текущим архивом, включая ссылки на внешние каталоги, записывать фактические пути версий файлов в журнал и очередь FTP. Файлы: BackupService, FileCopier, StorageManager и тесты соответствующих сервисов.
- [x] Поиск и устройства: проверять актуальную защиту перед удалением, не снимать фильтр при неизвестной камере, включать последнюю секунду дня целиком, различать сотрудников с одинаковыми именами. Файлы: SearchViewModel, DevicesViewModel, ArchiveSearch и их тесты.
- [x] Главное окно: исправить экранную клавишу C, закрытие окна без пароля, продление доступа при работе, состояние зарядки и индикацию недоступного архива. Отменённые отчёты копирования больше не меняют состояние, завершение задания меняет коллекции в потоке UI. Файлы: MainWindowViewModel, MainWindow.axaml.cs, MainWindow.axaml; ошибки воспроизведены до исправлений.
- [x] Настройки SQL: предлагать только поддерживаемый MySQL; при старом неподдерживаемом типе показывать ошибку до подключения, сохранять исходную настройку до явного выбора пользователя.
- [x] Проверить приложение на экране, выполнить полный набор тестов, собрать Release, провести независимый review и ponytail-review.

Исходная проверка: 253 теста проходят. Реальные накопители и серверы в проверках не используются.

Итог: 278 тестов проходят, Release собран без ошибок. Осталось исходное предупреждение CA1416 в Updater.cs:344. В тестовый проект добавлен Avalonia.Headless.XUnit 11.2.3 для проверки настоящего окна, входа и отрисовки вкладок без рабочего стола.

Главный экран и запрос данных осмотрены в отдельной запущенной копии с пустой базой. После ручного входа пользователя дальнейшие действия инструмента экрана завершались ошибкой GetCursorPos 0x80070005. Остальные вкладки и события окна проверены через headless. Физические USB, Linux-монтирование, реальная отправка FTP и подключение к внешней SQL-базе не проверялись. Защита от ссылок не исключает конкурентную подмену каталогов между проверкой и удалением.
