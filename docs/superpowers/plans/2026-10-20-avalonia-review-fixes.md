## P1

- [x] 1. SourceCleaner: тест подмены каталога/носителя во время очистки должен сохранять новые файлы; тест отмены должен останавливать удаление. Исправить проверку идентичности непосредственно при удалении и вызывающий код BackupService.
- [x] 2. BackupService: при полностью сохранённом источнике и недостатке места для его полного объёма чужие архивные записи остаются. Учитывать только дополнительный объём, включая новые версии изменённых файлов.
- [x] 3. WebPage: имя с кавычками и JavaScript остаётся данными; нажатие вызывает ровно ожидаемое действие с исходным путём. Убрать пользовательские строки из исполняемого onclick.
- [x] 4. Windows: обычный запуск установленной программы может создать настройки и базу без повышения прав. Выбрать минимальный путь установки/данных, не удаляющий прежние данные.
- [x] 5. Доступ: истечение сеанса закрывает просмотр и не допускает повторного открытия от запоздалого фонового результата.
- [x] 6. Linux: disabled/inactive Python unit не препятствует неинтерактивному обновлению C#; активный конфликт требует явной миграции.
- [x] 7. Пакет .deb отклоняет установку при активной Python-службе до изменения файлов и запуска C#.
- [x] 8. FTP: временное отсутствие или перемонтирование архива не стирает очередь, возвращённый файл остаётся доступным для отправки.

## P2

- [x] 9. /api/file не отдаёт файлы через ссылки, соседний каталог с другим регистром и неподтверждённый том; использовать защищённый доступ архива.
- [x] 10. Разные относительные пути одного имени сохраняются на FTP отдельно, очередь отмечается выполненной только после успешной отправки.
- [x] 11. Точный ID камеры имеет приоритет перед частичным совпадением имени/серийника; неоднозначное совпадение не выбирает случайную камеру.
- [x] 12. Отмена офлайн-обновления не допускает подготовки/запуска отменённого пакета после возврата к работе.
- [x] 13. Сохранённый таймаут применяется к текущему сеансу, в том числе 0 -> 1 и 1 -> 0.
- [x] 14. Перекрывающиеся Reload устройств, отделов и журнала не дублируют и не смешивают результаты; старое поколение не меняет текущее представление.
- [x] 15. install.sh без тега выбирает готовый C# v2.* своей архитектуры из списка релизов, не Python latest.
- [x] 16. Отсутствующая, пустая, некорректная или несовпадающая SHA256 запрещает установку до остановки служб и apt.
- [x] 17. Веб-панель строит ссылки и скачивает через актуальную точку монтирования архива.
- [x] 18. Снятая оператором привязка камеры к сотруднику не восстанавливается из legacy person при следующем открытии.
