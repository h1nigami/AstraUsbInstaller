# Стабильный релиз станции v2.0.9

> Исполнение: superpowers:executing-plans. Пользователь явно поручил выпустить стабильный релиз с текущим дизайном и сохранить отдельное обновление Python.

**Цель:** опубликовать C# v2.0.9 с новым интерфейсом, без статуса prerelease и без изменения общего latest v1.25.

**Архитектура:** Python получает releases/latest и архивы astra-usb-monitor-v1.*. C# выбирает готовые bestcam-station-v2.* из списка релизов. Стабильный C# публикуется с make_latest=false.

**Стек:** Avalonia 11.2.3, .NET 8, GitHub Actions, gh, unittest.

**Основание:** текущий запрос пользователя и согласованные изменения интерфейса в этом чате.

## Ограничения

- Тег выпуска указывает на коммит, уже вошедший в master.
- В релизе C# только архивы bestcam-station, пакеты .deb, установщик Windows и SHA256.
- Python-код и существующие Python-релизы не изменяются.
- Условия заданий сохраняют проверку семейства v2, включая ручной запуск и повторные запуски.
- Все действия публикации C# явно передают make_latest=false.

## Проверка рисков

- Стабильный v2 запускает все три задания C#, но не сборку Python.
- Тег v1 не запускает сборку и публикацию C#.
- Добавление вложений и изменение описания не переключают latest.
- Вложение без своей контрольной суммы не выбирается апдейтером.
- Восстановленные правки интерфейса и шрифты попадают в коммит выпуска.
