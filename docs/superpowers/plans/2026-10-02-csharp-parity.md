# Перенос защит и поведения Python в C#

> Выполнение: superpowers:executing-plans и независимые задачи через superpowers:dispatching-parallel-agents. Для каждой задачи сначала регрессионный тест, затем минимальная реализация.

Цель: закрыть пробелы из [сверки](../../review/2026-10-02-python-avalonia-parity.md), сохранив удаление физической разметки гнёзд.

Основание: пользователь попросил применить перечисленные изменения к C#.
Стек: .NET 8, Avalonia 11.2.3, SQLite и существующие xUnit-тесты.

## Ограничения

- Никаких новых зависимостей, миграции между продуктами или публикации релиза.
- Диапазон C# от 6 до 30 окон, важные записи и модель срока хранения сохраняются.
- Linux-назначение проверяется по физическому диску, UUID/serial и открытому каталогу. Неизвестное устройство запрещает запись и удаление.
- Копирование использует совместную блокировку, обслуживание и установка исключительную. Путь блокировки: `<dbPath>.operations.lock`.
- Повреждённые настройки не возвращают стандартный пароль и не затираются без явного восстановления.
- Рабочее дерево уже содержит удаление разметки. Его нельзя отменять.

## Задача 1. Блокировка операций и обновление

Файлы: `Services/OperationGuard.cs`, `Services/Updater.cs`, `avalonia/install_native.sh`, соответствующие тесты.

Контракт: `OperationGuard.Acquire(bool exclusive = false, string? dbPath = null)` возвращает `IDisposable`, при занятости бросает `StationBusyException`. Linux использует `flock`, Windows совместное/исключительное открытие файла. Установщик должен удерживать тот же замок; апдейтер передаёт установку без разрыва защиты.
