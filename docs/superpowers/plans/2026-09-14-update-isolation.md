# Изоляция обновлений Python и C#

**Цель:** закрыть семь ошибок из проверки апдейтеров: общий тег без проверки продукта, смешанные сборки, неточный выбор архива, копирование во время загрузки C#, ложное здоровье службы, зависание процессов и отсутствие отката при неверном VERSION.

**Решение:** Python использует `releases/latest`; C# выбирает готовый релиз `v2.*` своей платформы из списка, включая prerelease. Оба принимают только теги своего семейства и архив с точным именем. C# выпускается только как prerelease; общий latest остаётся за Python для совместимости со старыми апдейтерами. Новые зависимости не нужны.

**Стек:** Python stdlib, C#/.NET 8, bash, systemd, GitHub Actions.

- [x] Python: тестами воспроизвести чужой тег, неверное имя архива и несовпадение VERSION; ограничить выбор `v1.*`, откатывать неверную установку.
- [x] Запуск: проверить код завершения GUI 0 и 42 для обоих скриптов; использовать `exec`, чтобы systemd учитывал падения.
- [x] Сборки: Python только stable `v1.*`; оба задания C# только prerelease `v2.*` или ручная сборка `v2.*` с checkout указанного тега.
- [x] C#: тестами проверить выбор `v2.*`, блокировку при занятости перед установкой, таймауты процессов и откат при неверной версии; исправить соответствующие пути.
- [x] Проверить оба набора тестов, синтаксис bash, условия workflow и итоговый diff. Обновить инструкции о фактическом поведении.

Публикация нового релиза в этот план не входит.

Проверки: Python 162 теста в Linux (8 GUI-пропусков), 8 GUI-тестов и симуляция камер в Windows; C# 332 теста на .NET 8 в Windows. Четыре интеграционных сценария на Linux/.NET 8 прошли: занятость, неверный VERSION, перезапуски службы, успешная установка. Bash syntax, actionlint и 19 комбинаций условий workflow прошли.
