# План переноса Python v1.25 в Avalonia

> Исполнение: superpowers:executing-plans; независимые области через superpowers:dispatching-parallel-agents. Каждый изменяемый контракт проходит RED, GREEN и ревью.

**Цель:** перенести каждый поведенческий блок Python diff `382a3ac..2524f00` в C#.

**Архитектура:** существующие сервисы и ViewModel сохраняются. Общее журналирование связывает уже имеющиеся журналы действий и ошибок. MainWindowViewModel меняет один назначенный исполнитель; передача владения фиксируется до правок.

**Стек:** .NET 8, Avalonia 11.2.3, SQLite, xUnit.

**Спецификация:** [поведение и ограничения](../specs/2026-10-20-python-parity-design.md).

## Общие ограничения

- Не менять Python, версии зависимостей, форматы ID, каналы релизов и данные станции.
- Безопасность назначения, отмена, блокировки и сохранение оригиналов обязательны.
- Не запускать несколько dotnet build/test одновременно в общих bin/obj: использовать общий именованный mutex `AstraUsbInstallerParityTests`.
- Журналировать через существующий CrashLog.Write или ActionLog.Write; основной исполнитель связывает их с постоянным журналом.
- Commit, push и создание PR выполнять после явного запроса пользователя. Выпуск релиза и установку на станцию не запускать.

## Особые случаи для ревью

- Совпадающая версия с временным суффиксом должна остаться доступна поиску и безопасному удалению оригинала.
- Ошибка chmod при экспорте не удаляет успешно записанный файл; права backup сохраняются.
- Отказ обоих способов опроса не означает отключение камеры.
- Чужое монтирование и существующее /dev запрещают принудительное снятие.
- Старый файл, скопированный сегодня, находится по дате файла; отсутствие выделения экспортирует весь результат.
