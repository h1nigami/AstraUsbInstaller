# Автоматическая публикация стабильной Avalonia

> Исполнение: superpowers:executing-plans, в текущем изолированном worktree.

**Цель:** следующие стабильные релизы Avalonia автоматически появляются
в `bestcam-station` на `https://download.neuroii.ru`.

**Архитектура:** существующий workflow станции ждёт завершения Linux и Windows.
Новое задание скачивает вложения GitHub, проверяет состав и SHA-256,
загружает отдельный продукт, проверяет файлы через pilot и включает stable.
Для стабильных релизов используется событие `released`, для предварительных
сохраняется `published`. Это охватывает перевод prerelease в stable и исключает
двойную сборку при двух событиях нового стабильного релиза.

**Стек:** GitHub Actions, gh, curl, стандартная библиотека Python только для CI.
**Спецификация:** текущий запрос пользователя и правила разделения релизов AGENTS.md.

## Ограничения

- Приложения, workflow Python и продукт Viewer не меняются.
- Продукт издателя зафиксирован как `bestcam-station`, токен уже в `DOWNLOAD_STATION_TOKEN`.
- Тег строго `v2.X.Y`; draft, prerelease, чужие и неполные наборы запрещены.
- GitHub latest сохраняет назначение Python, права нового задания только contents:read.
- Повторный запуск завершает прерванную загрузку без перезаписи файлов.
- Версия ниже текущего stable пропускается, равная только проверяется.

## Проверки риска

- Прерванная загрузка и ответы 409 не должны оставлять неполный stable.
- Несовпавший существующий файл блокирует продвижение stable.
- Падение любого задания сборки исключает запуск издателя.
- События stable и prerelease выбирают ровно одну сборку.
- Секрет передаётся только API домена, скачивание файлов выполняется без токена.
