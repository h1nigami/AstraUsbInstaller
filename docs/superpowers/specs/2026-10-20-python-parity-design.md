# Полный перенос изменений Python v1.25 в Avalonia

Пользователь разрешил перенос всех изменений, TDD и проверки на своей машине. Эталон: Python `2524f00` (`v1.25`), предыдущий перенос: `382a3ac` (`v2.0.6`). Для каждого блока `git diff 382a3ac..2524f00 -- usb_monitor.py gui.py updater.py` нужен эквивалент C# или конкретное объяснение платформенного различия. Одного совпадения названий функций недостаточно.

## Поведение

- Копия учитывает уже сохранённые версии с суффиксом времени по размеру и mtime, не перезаписывает файлы и сохраняет правильный путь для поиска и удаления оригиналов.
- Прогресс считает обработанные файлы и байты, включая пропущенные совпадения. Статистика скопированного объёма учитывает только новые копии. Журнал не засоряется прогрессом пропущенных файлов.
- Экспорт сохраняет время файла без переноса Unix mode. Обычная резервная копия сохраняет права. Отказ копии сохраняет оригиналы, неполный результат удаляется.
- Ошибка опроса USB отличается от пустого списка. Повторы монтирования сохраняются после краткого исчезновения, причина отказа видна оператору. При подтверждённом исчезновении /dev разрешено lazy-размонтирование только собственных точек; остатки убираются при запуске. Чужие и действующие монтирования не затрагиваются.
- Сбои файлов, обхода, архива, миграций, фоновых задач, автоочистки и обновлений записываются с причиной. Повторяющиеся ошибки опроса подавляются до изменения или восстановления.
- Постоянный русский журнал находится в корне доступного архива, иначе в data/app.log. Переключение назначения и возврат диска меняют место записи; параллельные записи сохраняют целые строки с датой. Отключения и действия оператора также записываются. Диагностика включает журнал без секретов.
- Основной период поиска относится к mtime файла, без ограничения по времени сеанса. Дополнительный фильтр времени съёмки C# сохраняется. Выделенные файлы выгружаются отдельно; без выделения выгружается весь результат; счётчик кнопки обновляется при изменении выбора.
- Плашка диска архива показывает свободно/всего, процент занятости и отключение, использует реальный том каталога, предупреждает при свободном месте меньше 10 процентов. Обновляется в фоне.
- Семизначный ID уже реализован, существующие проверки LOG/DCIM сохраняются.

## Ограничения

.NET 8, Avalonia 11.2.3, существующие SQLite и xUnit. Новых зависимостей и обновления версий нет. Python не меняется. Разделение продуктов v1/v2, проверки архива, защита оригиналов, общая блокировка и функции C# сохраняются. Публикация и установка на рабочую станцию в эту задачу не входят. Проверки используют временные каталоги; реальные носители подключаются только для согласованного сценария.

## Проверка

Для каждого изменения сначала тест, наблюдаемый отказ по нужной причине, минимальная правка и успешный тест. Затем полный C#-набор на Windows, доступные Linux-интеграции и сборка XAML. Linux-операции проверяются существующими изолированными сценариями; отсутствие подходящей среды или физического носителя указывается явно.
