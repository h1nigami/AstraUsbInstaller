# Штатный выход во время обновления

Выход по паролю завершает Python GUI с кодом 0. Установщик через 3 секунды и апдейтер через 60 секунд требуют активную службу, поэтому штатный выход ошибочно вызывает откат и запись сбойного тега.

Общая `_service_healthy()` читает один снимок `systemctl show`. Допустимы работающая служба без аварийных перезапусков и завершённая служба `inactive/dead`, у которой `Result=success`, `ExecMainCode=1` (CLD_EXITED), `ExecMainStatus=0`, есть времена запуска и завершения, `NRestarts=0`. Незапускавшаяся служба, сигнал, ненулевой код, ошибка чтения состояния и перезапуски остаются ошибкой. Проверки импорта и совпадения VERSION не меняются.

Установщик использует ту же функцию из уже установленного приложения, чтобы штатный выход в первые 3 секунды тоже не считался ошибкой. Обновление сохраняется, программа остаётся закрытой. Отдельные маркеры выхода и изменение кода завершения GUI не нужны: systemd уже хранит необходимые сведения.

Проверки выполняются с моделируемым состоянием systemd и реальными временными файлами установки. Работа на физической станции проверяется отдельно. При первом переходе старый уже работающий апдейтер продолжает исполнять прежнюю проверку до завершения своего процесса.
