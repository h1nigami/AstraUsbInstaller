## Независимое ревью

Три новых агента проверили архив, интерфейс/веб/FTP и установщики. Они не
участвовали в реализации соответствующих областей. Во время ревью найдены
и исправлены следующие остатки:

- Используемую копию мог удалить собственный `FreeUpSpace`: четыре ожидаемых
  RED для обычной/версионированной копии с журналом и без него. Очистка теперь
  сохраняет точные пути, неиспользуемые записи того же устройства удаляются.
- Другой `RunAsync` мог удалить копию между расчётом и началом копирования:
  отдельный RED с двумя настоящими выгрузками. Повторная сверка и копирование
  удерживают один shared guard; при росте объёма подготовка повторяется.
  Недостижимый свободный резерв сам по себе не запускает повторную очистку.
- Отменённый пакет становился видим таймеру, а старый callback мог очистить
  чужой пакет: два RED. Теперь общий спул публикуется только после проверки
  поколения, а очистка касается собственного pending.
- Неактивный `static`-апдейтер Python блокировал установку: три RED.
  Дополнительно шесть RED подтвердили состояния activating/deactivating.
  Повторное независимое ревью проверило 27 комбинаций состояний.
- Тестовому контейнеру не хватало `python3`: подготовлен отдельный образ,
  успешный `package-guard` подтверждён CI.

Повторное ревью всех этих исправлений завершено без открытых P1/P2.
Последние связанные наборы: архив 187/187, офлайн-обновление 138/138.
Ponytail-review сохранения, очистки, блокировок и вызывающего кода выполнен.
Новых зависимостей приложения и общей сериализации копирований нет.

## Эксплуатационные границы

Физические USB, отдельный диск архива и внешний FTP в этой задаче не
использовались. Проверки установки и служб работают с отдельными стендами.
Файловая система Linux без `renameat2(RENAME_NOREPLACE)` безопасно откажет в
очистке и сохранит оригинал. Если во время возврата из карантина исходное имя
уже занято, файл сохраняется под `.astra-clean-*`, а журнал сообщает путь.

Для установки одной командой нужен системный `python3` для разбора JSON.
Новых зависимостей приложения нет. Windows-установка теперь пользовательская;
данные прежней установки в Program Files остаются на месте и требуют переноса
при закрытой программе.
